### 📂 Proyectos Destacados (42 Cursus)

Aquí puedes ver algunos de los retos de ingeniería de software que he superado:

*   **`push_swap`** 🔄: Optimización de algoritmos de ordenamiento mediante manipulación de stacks (`Stack A` y `Stack B`) con restricciones de complejidad temporal $O(N^2)$ y $O(N \log N)$.
*   **Codexion (Hilos y Concurrencia)** 🧵: Implementación de soluciones a problemas clásicos de sincronización de procesos usando hilos (threads), exclusión mutua (`mutex`) y prevención de *data races* y *deadlocks*.
*   **`born2beroot`** 🌐: Configuración y securización (*hardening*) de un servidor Linux (Debian) bajo CLI. Gestión de usuarios, sudoers, políticas estrictas de contraseñas, SSH por puerto seguro, UFW y scripts de monitoreo.
*   **Módulos de Python & `a-maze-ing`** 🐍 / 🗺️: Introducción a la Programación Orientada a Objetos, análisis de datos y algoritmos de búsqueda de caminos (*pathfinding* como BFS/DFS) en laberintos.
*   **`libft` & `get_next_line`** 📚: Reimplementación de funciones de la librería estándar de C y creación de un lector de archivos optimizado línea a línea gestionando dinámicamente la memoria (`malloc`/`free`).
